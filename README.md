The code for the simulations for the differential evolution results for the paper titled "Differential Evolution Applied to Optimal Design of Experiments: A Benchmarking Study" by Ritchie, Wisler, and Coster can be found here. The code for the simulations concerning PSO are not available here, but might be obtainable upon request from the authors of "Generating exact optimal designs via particle swarm optimization: Assessing efficacy and efficiency via case study" by Walsh and Borkowski. However, their function calls were used in an almost identical manner to the 02_sim.jl file with the proper inputs for swarm size, PSO version, etc. To run the simulations found in the first paper, change the file path to the local differential_evolution.jl directory and run the code. This will generate the data for the main text. The supplemental materials can be generated by using the same file, but changing the appropriate parameters (doArchive=true, or boundType="absorbingWall", or boundType="L-SHADE"). The plots can be generated using the post_processing_plots.R file after the analysis.
